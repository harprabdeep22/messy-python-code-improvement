Create a Python project named "Messy Python Code Improvement" for my college practical assessment.

The objective is to demonstrate how poorly written Python code can be improved using AI assistance.

Create these files:

1. messy_code.py
2. improved_code.py
3. README.md

In messy_code.py:

* Write a small, intentionally poorly formatted but functional Python program that calculates the total and average of a list of marks.
* Use unclear variable names, inconsistent spacing, and avoidable repetition.
* Keep the code safe and simple.
* Include a comment explaining that this is the original code before improvement.

In improved_code.py:

* Refactor the same program into clean, readable Python.
* Use meaningful variable names.
* Follow consistent formatting and standard Python naming conventions.
* Separate calculations into a reusable function.
* Validate input appropriately.
* Handle an empty list without division by zero.
* Preserve the intended functionality.

In README.md:

* Explain the original program.
* Explain the improvements made.
* Include a comparison of the original and improved code.
* Explain readability, maintainability, meaningful variable names, functions, and input validation.
* Include instructions for running both programs.
* Include sample input and output.

Do not claim that AI improves the program's performance unless you demonstrate and verify that claim. Explain every important change in beginner-friendly language and test both programs.
